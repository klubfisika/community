## 1. Filosofi Pendanaan

KF13 beroperasi di bawah prinsip yang jelas:

- **Misi tidak boleh dikompromikan oleh uang** — tidak ada investor yang bisa mengubah arah platform
- **Tidak ada iklan, tidak ada jual data** — pendapatan hanya dari sumber yang selaras dengan misi
- **Transparansi penuh** — setiap pemasukan dan pengeluaran dipublikasikan
- **Diversifikasi sumber** — tidak bergantung pada satu donatur atau grant tunggal
- **Komunitas sebagai pemilik** — pada saatnya, model pendanaan komunitas (open collective / DAO-style) lebih diutamakan dari sponsorship korporat

## 2. Sumber Pendanaan Jangka Pendek

*Target horizon: 0–12 bulan. Fokus pada bootstrap dan validasi.*

### 2.1 Unit Usaha Mandiri (Sudah Berjalan)

Klub Fisika Indonesia memiliki unit usaha yang pendapatannya menyubsidi pengembangan platform:

| Unit Usaha | Deskripsi | Status |
|-----------|-----------|--------|
| Merchandise sains | Kaos, poster, stiker bertema fisika dan sains | Berjalan |
| Kelas online | Persiapan olimpiade sains, metodologi riset | Berjalan |
| Buku dan modul | Modul fisika, panduan riset untuk pelajar | Berjalan |
| Event & workshop | Seminar sains, pelatihan guru | Berkala |
| Marketplace alat sains | Peralatan eksperimen untuk sekolah | Direncanakan |

### 2.2 Donasi Individu

Platform menerima donasi dari individu yang ingin mendukung misi tanpa syarat apapun.

**Mekanisme yang direncanakan:**
- GitHub Sponsors (untuk kontributor teknis)
- Open Collective (untuk transparansi komunitas)
- Transfer langsung via rekening yayasan

### 2.3 Crowdfunding Kampanye

Untuk milestone spesifik (peluncuran beta publik, fitur besar), kampanye crowdfunding terbatas bisa diluncurkan di:
- Kitabisa.com (untuk audiens Indonesia)
- Open Collective (untuk audiens internasional)

## 3. Sumber Pendanaan Jangka Menengah

*Target horizon: 1–3 tahun. Fokus pada skalabilitas dan keberlanjutan.*

### 3.1 Program Keanggotaan Institusi

Institusi yang mengadopsi KF13 untuk komunitas mereka bisa berkontribusi melalui program keanggotaan:

| Tier | Kontribusi/Tahun | Manfaat |
|------|-----------------|---------|
| **Mitra Sekolah** | Rp 500.000 – 2.000.000 | Badge verified school, prioritas onboarding |
| **Mitra Organisasi** | Rp 2.000.000 – 10.000.000 | Co-branding di platform, akses API lebih awal |
| **Mitra Institusi** | Negosiasi | Seat di advisory board, custom integration |

> Penting: Keanggotaan tidak memberikan kontrol atas arah platform. Hanya keuntungan operasional.

### 3.2 Layanan Profesional

- **Pelatihan**: Workshop penggunaan KF13 Index untuk guru dan pustakawan sekolah
- **Konsultasi**: Bantuan integrasi KF13 ke sistem informasi sekolah/dinas pendidikan
- **Kustomisasi**: Deployment KF13 untuk institusi tertentu (white-label dengan kontribusi balik ke komunitas)

### 3.3 API Premium

Setelah API publik stabil, institusi besar (kementerian, lembaga riset) bisa mengakses:
- API dengan rate limit lebih tinggi
- Akses data agregat untuk penelitian kebijakan
- Webhook dan notifikasi real-time

## 4. Sumber Pendanaan Jangka Panjang

*Target horizon: 3+ tahun. Fokus pada kemandirian ekosistem.*

### 4.1 Open Collective / Community Treasury

Model pendanaan komunitas di mana siapapun bisa berkontribusi dan semua pengeluaran transparan:
- Mirip model Wikipedia Foundation, tapi lebih kecil dan terfokus
- Komunitas memilih secara demokratis bagaimana dana digunakan

### 4.2 Endowment / Dana Abadi

Jika platform sudah mapan, membangun dana abadi (endowment) dari donasi besar satu kali yang diinvestasikan konservatif, dengan bunga/return yang digunakan untuk operasional.

Contoh model: Internet Archive, Wikipedia Foundation.

### 4.3 Integrasi Ekosistem Pemerintah

Jika KF13 diadopsi secara resmi oleh Kemendikbudristek atau BRIN sebagai infrastruktur nasional, pendanaan bisa datang dari:
- Anggaran Diknas untuk digitalisasi pendidikan
- Program BRIN untuk infrastruktur riset nasional
- Dana BOS (Bantuan Operasional Sekolah) yang dialokasikan untuk platform digital

### 5.4 Cara Mengajukan Grant

**Langkah umum:**
1. **Siapkan proposal**: visi, dampak terukur, anggaran detail, tim
2. **Track record**: dokumentasikan pengguna aktif, karya yang sudah diindeks, kontributor
3. **Impact metrics**: berapa sekolah yang terlibat, berapa karya siswa yang diselamatkan dari kepunahan
4. **Surat dukungan**: dari sekolah, dinas pendidikan, profesor, atau komunitas yang sudah menggunakan platform

## 6. Cara Berkontribusi Pendanaan

### Sebagai Individu

```
# GitHub Sponsors (direncanakan)
https://github.com/sponsors/klubfisika

# Open Collective (direncanakan)
https://opencollective.com/kf13

# Transfer langsung
Hubungi: [email kontak yayasan]
```

### Sebagai Institusi / Organisasi

Hubungi kami via GitHub Discussions atau email untuk membahas:
- Program kemitraan sekolah
- Adopsi platform untuk komunitas Anda
- Co-grant application (mengajukan grant bersama)

### Sebagai Kontributor Kode

Kontribusi kode **adalah** kontribusi finansial yang sangat berarti:
- Setiap fitur yang Anda kerjakan mengurangi biaya pengembangan
- Setiap bug yang Anda perbaiki meningkatkan kualitas platform
- Lihat [CONTRIBUTING.md](../CONTRIBUTING.md) untuk memulai

## 7. Transparansi Keuangan

KF13 berkomitmen untuk transparansi penuh. Ketika platform sudah menerima pendanaan eksternal:

- **Laporan keuangan** dipublikasikan setiap kuartal di repo ini
- **Semua keputusan pengeluaran besar** (>Rp 5.000.000) didiskusikan terbuka di GitHub Discussions
- **Tidak ada gaji eksekutif yang tidak wajar** — kompensasi tim dibatasi dan transparan
- **Open Collective** akan digunakan sebagai platform transparansi utama

```
docs/financial/
├── 2025-Q1-report.md    ← laporan keuangan per kuartal
├── 2025-Q2-report.md

```
